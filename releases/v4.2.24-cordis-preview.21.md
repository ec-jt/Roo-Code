# Roo Code 4.2.24 - Cordis preview 21

Extension version: **4.2.24**. Git tag: **v4.2.24-cordis-preview.21**. Experimental GitHub prerelease, not a stable or marketplace release.

## Fixes from the preview 20 review

- Reject OpenAI Native failed and incomplete terminal events in both SDK and manual stream paths. A failed nonempty partial summary is no longer accepted as successful compaction. Terminal errors expose only allowlisted protocol details.
- Restrict OpenAI Native fallback to SDK compatibility failures before streaming. Transport, cancellation, and generation errors no longer start an additional generation through adapter fallback.
- Stop after an empty, whitespace-only, or reasoning-only response to the single repaired overflow request. Such responses cannot re-enter the ordinary empty-response grace-retry loop.
- Key incremental usage and file-change contributions by row identity rather than timestamp. Same-millisecond rows no longer overwrite each other's accounting, including legacy request-finish pairs.
- Preserve unmerged command and MCP output when its parent request lies outside the bounded chat page. Render it as a collapsed standalone row. Command consolidation also uses row positions rather than timestamps.

The on-overflow policy, informational percentage bar, manual compaction, assistant-history editing, and single-stack background behavior remain in place. No authoritative history migration or deletion is performed.

## Validation and limits

Scoped runs passed 166 backend/provider/history tests, 11 command-consolidation tests, and 10 UI tests. Backend and webview type checks passed. Coverage includes partial-summary failure, incomplete terminal events, no fallback replay after output, cancellation, empty recovered responses, timestamp collisions, and page-boundary outputs.

No live-provider, full provider-matrix, interactive native-editor, or Mac memory-pressure test was performed. Providers must expose recognizable context-limit errors for automatic recovery. Summarization and large preserved inputs can still exceed provider limits and require manual intervention. The earlier Mac grey-panel incident remains unverified.

## Known unresolved preview findings

- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

Project memory remains opt-in. Cordis runtime preview remains off by default. Tool approval and storage settings are unchanged.

## Install and rollback

Install **roo-cline-4.2.24.vsix**, verify its SHA-256 checksum, then run **Developer: Reload Window** when ready to interrupt the extension session. Install separately on each extension host, including a separate Mac installation.

The previous 4.2.23 prerelease remains available for rollback, but retains the five defects fixed here. Resolve interrupted assistant edits before downgrading to versions older than 4.2.22. Rollback does not undo history edits or compaction, erase external memories, stop detached processes, or undo completed actions.
