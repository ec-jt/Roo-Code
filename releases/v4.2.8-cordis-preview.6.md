# Roo Code 4.2.8 - Cordis preview 6

Extension version: **4.2.8**. Git tag: **v4.2.8-cordis-preview.6**. This is a GitHub prerelease, not a stable or marketplace release.

## Context7 without a key

Context7 library search and documentation retrieval now work without configuring an API key. Missing, empty, and whitespace-only keys use anonymous access without an authorization header. A saved key remains optional for higher limits; this update does not delete credentials. Tool approval, mode restrictions, and explicit disable settings remain enforced.

The native integrations settings label the key optional and no longer disable Context7 toggles when it is absent. Live public searches and documentation requests returned HTTP 200 without credentials during verification. Anonymous access remains subject to service limits and availability.

Context7 returns indexed documentation, not a guarantee of the latest repository state. Check the relevant version and official source for version-sensitive behavior.

## Browser boundaries and lifecycle

- Browser destinations must use HTTP or HTTPS. Non-web URLs are rejected before launch approval and navigation. Document-request guards cover redirects and link/form navigation; committed URLs are checked before capture. Serve local previews over HTTP rather than opening local-file URLs.
- Web-to-Markdown fetching no longer disables Chromium's sandbox on Linux. Sandbox failures report guidance instead of retrying insecurely.
- Explicit remote-browser hosts take precedence over discovery caches. An explicit connection failure does not select another host.
- Local/remote relaunches release the previous owned session before replacement. Task teardown awaits browser cleanup and prevents pending launches from attaching after disposal. Externally managed remote browsers are disconnected, not terminated.

## OAuth and Codex

- A failed refresh of old credentials no longer cancels an unrelated replacement sign-in. Credential revisions, serialized storage, and explicit sign-out cancellation retain stale-operation protection.
- Codex failed and incomplete terminal events now report sanitized diagnostics in SDK and manual SSE paths. Terminal errors do not trigger transport fallback or authentication replay. Event-processing failures are no longer swallowed as JSON parsing errors.

## Validation and limits

The combined release regression run passed 1,179 tests across 55 backend suites, with ten existing skips, plus 31 tests across four UI suites. Context7 coverage includes keyless/authenticated requests, approval, availability, and settings controls. Backend and webview no-emit type checks and targeted lint passed.

Browser launches and provider responses use mocks in regression tests. Real macOS/Windows Chrome behavior, Linux sandbox policy, and live OAuth sign-in still require platform verification. Browser navigation guards are defense in depth, not a complete OS sandbox. Context7's optional-key wording follows the existing English native-integrations UI.

Cordis runtime preview remains off by default. No approval settings are enabled by this update. Graph execution and strict financial budget enforcement remain unavailable.

## Installation and rollback

Install **roo-cline-4.2.8.vsix**, verify the accompanying SHA-256 checksum, and run **Developer: Reload Window**. The extension ID is unchanged. Start a new task if an existing conversation retains an older tool list.

The previous 4.2.7 prerelease remains available for rollback but retains the Context7 key requirement and the browser/OAuth/stream issues fixed here. Rollback cannot undo completed task actions.
