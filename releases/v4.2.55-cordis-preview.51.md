# Roo Code 4.2.55 - Cordis preview 51

Extension version: **4.2.55**. Git tag: **v4.2.55-cordis-preview.51**. Experimental GitHub prerelease, not a stable or marketplace release.

## Subtask links resolve from an explicit message-to-child map

Subtask links in a parent task now resolve from a map recorded at delegation time. The approved `new_task` message timestamp is stored against the child task ID it created, and that row uses its own entry. The previous behavior counted `new_task` messages and indexed the parent's append-only `childIds` array, so any divergence shifted later links to older children. Replayed UI history, a failed and retried delegation, and restored history could all cause that divergence.

Tasks recorded before this release have no map. They keep the previous index behavior.

## Delegation lifecycle unchanged

`childIds`, `delegatedToId`, `awaitingChildId`, completion, resume and deletion semantics are unchanged. `childIds` stays append-only. The map is additive and optional in task history, and it is only written when a delegation supplies a message timestamp. A link entry is ignored when its child ID is not present in `childIds`, which keeps the fallback safe for partially recorded tasks.

This release does not migrate, inventory, read, rewrite, prune or delete existing task data.

## Features retained from 4.2.51 to 4.2.54

Browser controls with auto-approval for every rich command, native PDF reading, mode/model preservation, the DeepSeek strict tool-schema fix and the single read-only browser approval are unchanged. See the [4.2.54 release notes](v4.2.54-cordis-preview.50.md), [4.2.53 release notes](v4.2.53-cordis-preview.49.md), [4.2.52 release notes](v4.2.52-cordis-preview.48.md) and [4.2.51 release notes](v4.2.51-cordis-preview.47.md).

## Validation and limits

Focused implementation evidence: 11 backend delegation tests and 9 subtask-link UI tests pass, covering explicit-link precedence over stale order, the legacy fallback and rejection of unknown link entries; backend and webview TypeScript checks pass. Release gates cover isolated lint, packaging, isolated backend TypeScript checking, ZIP CRC and manifest identity, both worker bundles, feature markers, absence of unfinished provider-connection markers, presence of `newTaskChildLinks` in the built bundle, source-to-commit hashes, asset SHA-256, GitHub server digest and size, and installed-file byte identity. These gates are not a full test suite, and installation does not imply activation.

Live browser behavior, extension activation, macOS behavior and end-to-end user workflows remain unverified.

## Storage and rollback warnings carried forward

Versions 4.2.48 and earlier cannot replay version-2 request snapshots. Rolling back does not convert snapshots. Preserve task storage before downgrading, and disable automatic updates before a deliberate rollback.

Closing a task blocked by an interrupted edit marker can overwrite UI history with an empty snapshot. Preserve the task directory before recovery. Avoid navigation while saving history edits.

Unfinished provider-connection checks and unrelated local editor, UI, Tetris, archive and research changes are excluded.

## Installation

Verify the attached VSIX against its SHA-256 file. Install separately on each extension host. This release operation installs only on the current Linux code-server host, without reloading the editor or activating the new extension. It does not install on a Mac. The companion ZIP is optional, unchanged from 4.2.51 to 4.2.54, and requires separate manual Chrome installation.
