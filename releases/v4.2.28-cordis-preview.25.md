# Roo Code 4.2.28 - Cordis preview 25

Extension version: **4.2.28**. Git tag: **v4.2.28-cordis-preview.25**. Experimental GitHub prerelease, not a stable or marketplace release.

## Restore task without restoring files

The checkpoint menu now offers three independent choices:

| Choice                 | Conversation                      | Workspace files          |
| ---------------------- | --------------------------------- | ------------------------ |
| Restore files          | Keep current history              | Restore checkpoint files |
| Restore task only      | Rewind to the checkpoint boundary | Keep current files       |
| Restore files and task | Rewind to the checkpoint boundary | Restore checkpoint files |

- **Restore task only** requires confirmation because later conversation messages are removed from the current task. It is an in-place rewind, not a new branch.
- Skip Git checkpoint initialization and restoration, managed-environment compatibility inspection, and the restored-workspace commit notification for task-only mode.
- Reuse the conversation rewind path to clean up removed summaries and truncation markers. Preserve deleted-request accounting.
- Require settled execution and terminals. Refuse active edits rather than canceling an edit that could revert workspace files.
- Support task-only rewind when the historical checkpoint conversation entry exists but its Git object is unavailable.

Current files can contain changes made after the restored conversation boundary. Review them before resuming. Completed external actions and child tasks are not undone. See [checkpoint restore options](../docs/checkpoint-restore.md).

## Validation and limits

28 backend checkpoint tests and 7 UI tests passed. Backend and frontend type checks passed. Coverage includes task-only rewind, no Git restore, missing checkpoint service, persistence failure, confirmation, and switching restore choices. Interactive VS Code behavior and real-filesystem fault injection were not tested.

Compaction still requires active input to fit the selected model. Context recovery branches require exact pre-event snapshots; older events without snapshots remain unsupported. This release does not change those limits.

## Known unresolved findings

- **Closing a task blocked by an interrupted assistant-edit marker can overwrite its UI history with an empty snapshot.** Preserve the task directory before attempting recovery.
- **Closing or switching during an assistant edit can leave the task stuck after a safe rollback.** Avoid navigation while an edit is saving.
- Checkpoint-based user edits can be dropped if replacement history loading exceeds the fixed continuation delay. This is separate from the checkpoint-menu restore operation.
- Approving an unrelated command can mark an older denied file edit as approved in the UI and file summary. This does not execute the denied write.
- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

Project memory remains opt-in. Cordis runtime preview remains off by default. New task-only labels use English. The Mac grey-panel incident remains unverified.

## Install and rollback

Install **roo-cline-4.2.28.vsix**, verify its SHA-256 checksum, then run **Developer: Reload Window** when ready to interrupt the extension session. Install separately on each extension host.

The previous 4.2.27 prerelease remains available without the task-only menu option. Do not open unfinished recovery branches in versions below 4.2.26, which do not enforce their preparation marker. Resolve interrupted assistant edits before downgrading below 4.2.22. Rollback does not recover rewound conversation messages, undo history edits, remove truncation tags, restore files, erase memories, or stop detached processes.
