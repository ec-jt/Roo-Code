# Roo Code 4.2.56 - Cordis preview 52

Extension version: **4.2.56**. Git tag: **v4.2.56-cordis-preview.52**. Experimental GitHub prerelease, not a stable or marketplace release.

## Closed or detached browser pages fail with a clear message

A browser action that reaches a page which is already closed, or a browser that has disconnected while a page reference remains, now fails before the legacy screenshot path runs. The session resets stale browser state, reports the browser as inactive, and throws:

> The browser page was closed or detached. Relaunch the browser before retrying; the previous action was not retried.

Previously the raw CDP error `Protocol error (Page.captureScreenshot): Not attached to an active page` surfaced from the screenshot call. The new guard runs after the existing missing-session check and before the page action.

## No automatic retry

The guard does not retry the previous action, and no other browser behavior changes. Callers must relaunch the browser and repeat the action deliberately.

## Features retained from 4.2.51 to 4.2.55

Browser controls with auto-approval for every rich command, native PDF reading, mode/model preservation, the DeepSeek strict tool-schema fix, the single read-only browser approval, and subtask links resolved from an explicit `new_task`-to-child map are unchanged. See the [4.2.55 release notes](v4.2.55-cordis-preview.51.md), [4.2.54 release notes](v4.2.54-cordis-preview.50.md), [4.2.53 release notes](v4.2.53-cordis-preview.49.md), [4.2.52 release notes](v4.2.52-cordis-preview.48.md) and [4.2.51 release notes](v4.2.51-cordis-preview.47.md).

## Installed version requires a reload

Installing a VSIX does not activate it. A running editor keeps its current extension version until the extension host reloads. An editor that still reports an older version after a successful install has not reloaded.

## Validation and limits

Focused implementation evidence: 50 `BrowserSession` tests pass, including the closed-page and disconnected-browser cases; backend TypeScript checking passes; scoped Prettier and whitespace checks are clean. Release gates cover isolated lint, packaging, isolated backend TypeScript checking, ZIP CRC and manifest identity, both worker bundles, feature markers, absence of unfinished provider-connection markers, presence of the closed-or-detached message in the built bundle, source-to-commit hashes, asset SHA-256, GitHub server digest and size, and installed-file byte identity. These gates are not a full test suite.

Live browser relaunch behavior, extension activation, macOS behavior and end-to-end user workflows remain unverified.

## Storage and rollback warnings carried forward

Versions 4.2.48 and earlier cannot replay version-2 request snapshots. Rolling back does not convert snapshots. Preserve task storage before downgrading, and disable automatic updates before a deliberate rollback.

Closing a task blocked by an interrupted edit marker can overwrite UI history with an empty snapshot. Preserve the task directory before recovery. Avoid navigation while saving history edits.

Unfinished provider-connection checks and unrelated local editor, UI, Tetris, archive and research changes are excluded.

## Installation

Verify the attached VSIX against its SHA-256 file. Install separately on each extension host. This release operation installs only on the current Linux code-server host, without reloading the editor or activating the new extension. It does not install on a Mac. The companion ZIP is optional, unchanged from 4.2.51 to 4.2.55, and requires separate manual Chrome installation.
