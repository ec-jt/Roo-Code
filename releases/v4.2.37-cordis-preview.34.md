# Roo Code 4.2.37 - Cordis preview 34

Extension version: **4.2.37**. Git tag: **v4.2.37-cordis-preview.34**. Experimental GitHub prerelease, not a stable or marketplace release.

## Valid JSON diagnostic exports

- Remove the two leading comment lines from newly generated diagnostic reports. Strict JSON editors no longer report comments as syntax errors.
- Keep sharing and privacy guidance in a normal JSON field. Reports still contain conversation history and must be reviewed and redacted before sharing. Nothing is uploaded automatically.
- Write reports through the atomic JSON writer with readable formatting. Preserve error metadata, history, and the review-in-editor workflow.

Existing exported reports are not rewritten. For an old report, remove its two leading comment lines or open it in JSON with Comments mode. This change does not fix the underlying error described inside a report. Informational activation warnings for bundled code-server Git extensions are unrelated and those manifests are unchanged.

## Validation and limits

Five focused diagnostic-export tests passed, including metadata/history, defaults, missing or malformed history, and write failures. The writer is mocked in these tests; real-filesystem fault injection and interactive installed-extension export were not performed. Release lint, packaging, archive integrity, and checksum checks are required by the release procedure.

Earlier ripgrep, Settings/MCP, LM Studio, and new-task model-selection fixes remain included. Ensure manually installed ripgrep is on the extension host's inherited PATH, not only an interactive shell's PATH. Authenticated LM Studio behavior remains mock-tested; legacy SDK operations can outlive the caller timeout. Claude and DeepSeek thinking-model switching through LiteLLM remains incomplete and unverified. Pinned replay and the experimental Anthropic-only mediated runtime retain their restrictions.

## Known unresolved findings

- Subtask links can select the wrong child after earlier delegation messages leave the bounded page, or when historical results use the latest completed-child ID.
- Long command-output previews can freeze on the beginning instead of following the tail.
- Image-only historical/preview messages can appear empty.
- Historical truncation events can hide structured count, reason, and token metrics.
- Same-millisecond timestamps can share expansion state or confuse timestamp-based lookups.
- **Closing a task blocked by an interrupted edit marker can overwrite UI history with an empty snapshot. Preserve the task directory before recovery.**
- **Closing or switching during a history edit can leave a task stuck after rollback. Avoid navigation while saving.**
- An unrelated approval can mark an older denied file edit as approved in the UI without executing that write.
- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

The pre-existing historical-action guard fixture failure remains outside this change. Project memory remains opt-in. Cordis runtime preview and automatic GitHub updates remain off by default. Browser security and SSH setup remain manual. The Mac grey-panel incident remains unverified.

## Install and rollback

From 4.2.30 or later, use **Settings > About > GitHub release updates** after closing the loaded task. A stopped or completed task still counts as loaded: return to the empty New Task screen without deleting history. Alternatively install the attached VSIX and verify its SHA-256 checksum. Run **Developer: Reload Window** when ready to activate it. Install separately on each extension host. End-to-end in-app Remote SSH installation remains unverified.

The previous 4.2.36 prerelease remains available. Disable automatic GitHub updates before a deliberate rollback. Versions below 4.2.34 do not support the LM Studio token field. Versions below 4.2.29 do not honor the separate truncation-fallback preference. Do not open unfinished recovery branches in versions below 4.2.26. Resolve interrupted history edits before downgrading below 4.2.22. Rollback does not recover rewound messages, undo edits, restore files, erase memories, or stop detached processes.
