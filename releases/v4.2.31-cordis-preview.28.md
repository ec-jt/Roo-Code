# Roo Code 4.2.31 - Cordis preview 28

Extension version: **4.2.31**. Git tag: **v4.2.31-cordis-preview.28**. Experimental GitHub prerelease, not a stable or marketplace release.

## Refresh stale model dialogs

- Add **Refresh current request** when a model restart/regeneration dialog becomes stale as the task advances.
- Preserve the selected saved profile, capture the current request revision, and require fresh workspace confirmation before dispatch.
- Refuse refresh across task instances. Keep restrictions for delegated tasks, admitted/executed tools, pending approvals, active edits, and unavailable request snapshots.
- Display the current blocking reason rather than leaving only an unexplained disabled action. The Code/Architect mode selector is separate from this model-profile restart dialog.

## Restore editing for large user messages

- Show **Edit** for the user's own bounded-preview messages on the latest page. Load authoritative stored text and attachments before allowing Save, never a truncated prefix.
- Validate task, instance, row index, revision and timestamp during retrieval and through Save/Confirm. Refuse ambiguous timestamp references in the new correlated flow.
- Preserve an unsaved draft if history changes; disable Save and explain how to reopen safely. Keep attachments in both edit-confirmation choices.
- Retain existing confirmation and rewind/resubmit semantics: a confirmed user edit discards later conversation and resumes from the edited input.

Historical pages remain read-only, and the pinned root prompt is not edited by this new control. Return to latest to edit messages available there. Inline retrieval is bounded to 8 MiB text and 1 MiB attachments; exceeding a bound reports an error rather than silently dropping content. The existing checkpoint-edit continuation defect below remains unresolved.

## Known unresolved UI findings

- Subtask links can map to the wrong child after earlier delegation messages leave the bounded page, or when earlier results use the latest completed-child ID.
- Long command-output previews can freeze on the beginning of the text instead of following its tail.
- Image-only historical/preview messages can appear empty; the simplified renderer does not render retained images.
- Historical truncation events can hide their structured count, reason and token metrics.
- Same-millisecond message timestamps can share row expansion state or confuse timestamp-based UI lookups.

## Other known unresolved findings

- **Closing a task blocked by an interrupted assistant-edit marker can overwrite its UI history with an empty snapshot.** Preserve the task directory before attempting recovery.
- **Closing or switching during an assistant edit can leave the task stuck after a safe rollback.** Avoid navigation while an edit is saving.
- Checkpoint-based user edits can be dropped if replacement history loading exceeds the fixed continuation delay.
- Approving an unrelated command can mark an older denied file edit as approved in the UI and file summary. This does not execute the denied write.
- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

Project memory remains opt-in. Cordis runtime preview and automatic GitHub updates remain off by default. New labels/help use English. Browser host security and SSH setup remain manual. The Mac grey-panel incident remains unverified.

## Install and rollback

From 4.2.30, use **Settings > About > GitHub release updates** after closing the loaded task. Alternatively install **roo-cline-4.2.31.vsix** and verify its SHA-256 checksum. Run **Developer: Reload Window** when ready to activate the new version. Install separately on each extension host; end-to-end in-app Remote SSH installation remains unverified.

The previous 4.2.30 prerelease remains available. Disable automatic GitHub updates before a deliberate rollback. Versions below 4.2.29 do not honor the separate truncation-fallback preference. Do not open unfinished recovery branches in versions below 4.2.26. Resolve interrupted assistant edits before downgrading below 4.2.22. Rollback does not recover rewound messages, undo edits, restore files, erase memories, or stop detached processes.
