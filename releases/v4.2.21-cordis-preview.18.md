# Roo Code 4.2.21 - Cordis preview 18

Extension version: **4.2.21**. Git tag: **v4.2.21-cordis-preview.18**. Experimental GitHub prerelease, not a stable or marketplace release.

## Compact chat presentation

- Put the history message count and navigation buttons on one compact row, with buttons right-aligned. Long counts truncate on narrow panels and remain available on hover.
- Display API timing and cache metrics inline beside the request label, with cost on the right. Metrics wrap when needed; cache-expiry information remains visible.
- Expand thinking sections by default. Explicitly saved Collapse thinking preferences remain respected, and individual sections can still be collapsed.
- Collapse large-history tool previews by default. Show preview reveals the bounded preview; Open full message opens the stored content in the native editor. Pending live approval details remain visible.
- Collapse command output by default for integrated and background commands. Command text, status, and controls remain visible. Shell-integration fallback no longer forces output open, and hidden output is not rendered until expanded.

These are presentation changes. They do not change tool approval policy, command execution, or authoritative history storage. New compact controls use English labels.

## Validation and limits

All 34 focused command-output and bounded-chat tests passed. Formatting and patch checks passed. No interactive Mac visual or memory-pressure test was performed. The earlier Mac grey-panel incident remains unverified.

The large-history limits from preview 17 remain: full backend history and whole-history JSON copies still consume memory, the chat projection budget does not cap all extension state, and unanswered approvals may exceed the normal payload budget. Save queues remain process-local rather than cross-process transactions.

## Known unresolved preview findings

The four preview 14 review findings remain unresolved:

- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

Project memory remains opt-in. Cordis runtime preview remains off by default. Existing approval and storage settings are unchanged.

## Install and rollback

Install **roo-cline-4.2.21.vsix**, verify its SHA-256 checksum, then run **Developer: Reload Window** when ready to interrupt the extension session. Install separately on each extension host, including a separate Mac installation.

The previous 4.2.20 prerelease remains available for rollback. Rollback does not erase task history or external memories, stop detached processes, or undo completed actions.
