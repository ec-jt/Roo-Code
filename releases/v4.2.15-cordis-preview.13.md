# Roo Code 4.2.15 - Cordis preview 13

Extension version: **4.2.15**. Git tag: **v4.2.15-cordis-preview.13**. This is a GitHub prerelease, not a stable or marketplace release.

## Request responsiveness

- Present each streamed chunk before waiting for the next provider chunk. This removes a one-chunk display delay, including when the provider pauses after sending text.
- Anthropic diagnostic disk writes are asynchronous and best effort rather than blocking request dispatch. Diagnostic completion order is not guaranteed, and pending logs may be lost on process exit.
- Remove per-chunk cancellation listeners after each wait completes instead of accumulating them over a long stream.

## Request timing and cache visibility

- API request rows show local preparation time, time to the first provider chunk, and the current preparation/waiting/receiving phase.
- Preparation includes context and request snapshots. First-chunk timing includes provider setup, network, and any retries; it is not a server-side measurement or necessarily the first visible text token. The configured rate-limit wait is shown separately.
- Show reported cache-read tokens, their percentage of total input, and cache-write tokens. Distinguish explicit zero cache reads from unavailable telemetry where the provider adapter preserves that distinction.
- Cache expiry is labelled **not reported by provider**. No cache-expiry countdown or guarantee of future cache hits is inferred.
- The ten new labels use English fallback in other locales, as requested.

These changes do not change model selection, reasoning effort, provider rate limits, approval settings, or cache retention policy. Cordis runtime preview remains off by default.

## Validation and limits

118 focused tests passed: 71 Anthropic provider tests, 44 task-loop tests, and three request-metrics UI tests. Backend and webview type checks passed. Tests cover first-chunk presentation while the next chunk is pending and usage accounting for normal and interrupted streams.

No live provider latency benchmark or live-editor visual smoke test was performed. The changes remove local blocking and display delay; they do not establish the cause of every long request or promise faster provider generation. Non-English translations of the new labels remain deferred.

## Install and rollback

Install **roo-cline-4.2.15.vsix**, verify the accompanying SHA-256 checksum, and run **Developer: Reload Window**. The extension ID is unchanged.

The previous 4.2.14 prerelease remains available for rollback. Rollback removes these responsiveness and display changes and cannot undo completed task actions.
