# Roo Code 4.2.7 - Cordis preview 5

Extension version: **4.2.7**. Git tag: **v4.2.7-cordis-preview.5**. This is a GitHub prerelease, not a stable or marketplace release.

## Browser selection and safety

- Managed Chromium remains the default. Settings > Browser now offers **Installed Google Chrome (macOS/Windows)** from standard system or per-user installation locations.
- Chrome runs on the VS Code extension host with a separate Roo profile, not your personal browser profile. Missing Chrome produces an error without downloading or switching browsers. Remote mode preserves but disables local browser settings.
- **Show browser window** now works without Linux display variables on native macOS and Windows. Linux sandbox and display protections remain in place.
- Launching a session no longer removes another active session's temporary profile. Each session cleans up only its own profile.
- Screenshot files require destination-specific write approval and must satisfy ignore rules and mode write restrictions. Symlink paths and hard-linked destinations are rejected. Filesystem checks mitigate path races but are not a complete sandbox against hostile concurrent directory replacement.
- The standalone browser panel now follows live activity updates after its initial state snapshot.

## Authentication and providers

- Cancelled or superseded OAuth refreshes and authorization exchanges cannot restore credentials after sign-out or overwrite a newer account. Credential storage operations are serialized.
- The OAuth callback listener binds to IPv4 loopback. Invalid callbacks no longer terminate legitimate sign-in. Expected cancellation no longer produces a failure notification.
- Codex fallback and authentication retries cannot combine partial output with a second generation. Streaming failures and cancellation do not trigger transport fallback.
- DeepSeek thinking and continuation formatting follow retained reasoning-model capabilities, including V4 Pro.
- Includes the preceding branch's native tool-call finalization and malformed-call retry-loop fixes.

## Validation and limits

The implementation's combined regression run passed 412 tests across 18 suites, with seven existing skips. Backend, webview, and shared-types checks and targeted lint passed. The release-preparation backend run passed 437 tests across 17 suites, with seven existing skips, including packaged-asset and native-tool regressions. The forced production VSIX build passed archive integrity checks; its metadata reports 4.2.7 and it contains no environment files.

Browser launches are mocked in platform tests. Real macOS/Windows Chrome launches, live OAuth sign-in, and live provider responses were not verified on the Linux build host. New browser-selection wording uses English fallback; other translations remain pending. Local environment files are excluded from packages and are no longer copied during extension builds.

Cordis runtime preview remains off by default. No approval setting is enabled by installing this update. Graph execution and strict financial budget enforcement remain unavailable.

## Install and rollback

Install **roo-cline-4.2.7.vsix**, verify it against the accompanying SHA-256 file, then run **Developer: Reload Window**. The extension ID is unchanged.

After reloading, select a browser in **Settings > Browser**, optionally enable **Show browser window**, save, and launch a new session. In remote environments, the extension host is not necessarily the desktop displaying VS Code.

The previous 4.2.6 prerelease remains available for rollback, but it does not include these browser, authentication, or provider fixes. Rollback cannot undo completed task actions.
