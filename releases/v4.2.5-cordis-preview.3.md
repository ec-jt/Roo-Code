# Cordis runtime preview 3

Extension version: **4.2.5**. Git tag: **v4.2.5-cordis-preview.3**. This is a GitHub prerelease, not a marketplace or stable release.

## Access and task lifecycle fixes

- Markdown conversion accepts only HTTP and HTTPS URLs. Local files must use the path branch, which retains workspace approval and ignore-rule checks. Validation runs before approval and at the shared fetcher boundary.
- Closing an unfinished child or opening unrelated history preserves its pending return to the parent. Reopening the child can then complete the delegation normally.
- Explicitly resuming a waiting parent revokes its pending child return. Children whose parent has advanced, or whose linkage was already cleared by an older build, remain rejected rather than being reattached without evidence.

## Preview recovery

- Failed or denied preview requests finalize request presentation and wait for explicit continuation instead of leaving a busy request or automatically retrying.
- Text-only responses remain interactive; the next user message starts the next admitted request.
- Failed manual condensation reports the error and clears the webview busy state.
- Disabling preview still fences further dispatch for affected instances. Reopen the task to use the current setting. Re-enabling does not automatically resume a stopped instance.

## Timeout behavior

The default API request timeout is now **0**. Integrated OpenAI/Anthropic SDK transports have no client inference-wait or streaming deadline at zero. Explicit positive settings still apply per attempt until response headers arrive, not to total stream duration. Cancellation remains active.

Connection-establishment, server, proxy, operating-system, and network limits still apply. Existing saved positive settings are not overwritten. Non-SDK provider transports are not changed by this adapter. The adapter relies on the installed SDK transport hooks and has actual-SDK regression coverage.

Only the English timeout description is updated in this preview. Other languages still show the old default until their wording is refreshed.

## Validation and known limits

- Combined backend regression run: 281 passed, 6 skipped across 12 suites. Backend TypeScript checking passed.
- Additional focused provider/SDK run: 313 passed, 1 skipped across 14 suites.
- The broader provider suite is not fully green: 63 failures reproduced against the pre-change baseline; no new failures remained in the comparison.
- Tests cover synthetic local-file URL rejection without opening private files, child close/reopen and stale-return rejection, preview continuation/failures/cancellation, condensation cleanup, and actual SDK timeout/cancellation behavior.
- No live model-provider or cross-platform extension-host validation was performed. Existing unrelated localization gaps remain.

Cordis preview remains **off by default**. Graph execution and strict financial budget enforcement remain unavailable. The existing checkpoint storage protections remain in place; old checkpoint history is not pruned.

## Install and rollback

Install **roo-cline-4.2.5.vsix**, then run **Developer: Reload Window**. The extension ID is unchanged. The accompanying SHA-256 file verifies the release artifact.

The previous 4.2.4 prerelease remains available for rollback, but it retains the access-boundary and lifecycle issues fixed here. Rolling back does not undo completed actions or repair previously cleared delegation metadata.
