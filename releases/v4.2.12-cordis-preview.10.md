# Roo Code 4.2.12 - Cordis preview 10

Extension version: **4.2.12**. Git tag: **v4.2.12-cordis-preview.10**. This is a GitHub prerelease, not a stable or marketplace release.

## New models

- **OpenAI ChatGPT Plus/Pro: GPT-6.1 Sol**, model ID `gpt-6.1-sol`. Context 1,050,000 tokens, maximum output 128,000 tokens, image input, reasoning effort low/medium/high/xhigh/max with medium default. None and minimal are unsupported; stale unsupported settings fall back to medium. Cost estimates remain zero for subscription usage. Account entitlement and backend availability still determine access.
- **Anthropic: Claude Opus 5.5**, model ID `claude-opus-5-5`. Native 1M context, 128K output, image input, prompt caching, and always-on adaptive thinking with medium default effort. Standard per-million-token pricing: $4 input, $20 output, $5 five-minute cache writes, $0.20 cache reads.
- **Claude Fable 5.1** was already available. Its catalog and high default effort remain. No official Fable 5.2 listing was found, so no speculative model ID is added.

Existing selections and provider defaults are unchanged. This update targets ChatGPT subscription and direct Anthropic providers, not the direct OpenAI API, Bedrock, Vertex, or router catalogs.

## Compatibility

Opus 5.5 and Fable 5.1 retain adaptive thinking despite stale disable settings and omit unsupported forced tool choices. Summarized thinking is requested for progress visibility.

Their documented thinking-binding compatibility beta allows the API to drop prior thinking blocks whose prefix no longer matches after Roo edits prompts/tools or condenses history. This prevents a request rejection but may reduce continuity of affected reasoning. Thinking blocks and signatures remain unmodified locally.

## Validation and limits

108 focused tests passed: five Anthropic catalog tests, 69 Anthropic request tests, and 34 Codex model/request tests. Backend type checking and targeted lint passed. No live paid inference or account-entitlement validation was performed. Earlier browser, checkpoint, tool-gating, and delegation changes remain included. Cordis runtime preview remains off by default.

## Install and rollback

Install **roo-cline-4.2.12.vsix**, verify the accompanying SHA-256 checksum, and run **Developer: Reload Window**. Select the desired model in provider settings after reload. The extension ID is unchanged.

The previous 4.2.11 prerelease remains available for rollback. Select a model supported by that version before reverting; rollback cannot undo completed task actions.
