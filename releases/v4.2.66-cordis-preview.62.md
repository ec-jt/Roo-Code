# Roo Code 4.2.66 - Cordis preview 62

Extension version: **4.2.66**. Git tag: **v4.2.66-cordis-preview.62**. Experimental GitHub prerelease, not a stable or marketplace release.

## Subtasks receive the architecture IDs in scope

When a task delegates with `new_task`, Roo now appends one line to the subtask message:

```
Architecture IDs in scope: C-6, Q-REL-2, ADR-2026-11-13-overflow-only-context-recovery
```

An ID is included only when both are true:

- it appears in the parent's latest architecture context block (so it exists in `docs/architecture/`), and
- the parent cited it: in the delegation message, in its task-state ledger, or in its own replies.

IDs that appear only in the block's index are not passed. The list keeps citation order and is capped at 30 IDs. Nothing is added when the parent has no architecture block (for example, when **Architecture context** is Off) or cited nothing.

The line only scopes the subtask. The subtask's own architecture context still supplies the records, according to its own settings.

## Validation and limits

Focused tests pass: the architecture context spec (21 tests, including ID scoping, citation order, unknown IDs dropped, and no block), the provider delegation spec (15 tests, including the appended line and its absence without a block), and the new-task delegation spec. Extension TypeScript checking and lint pass. Release gates cover lint, packaging, VSIX ZIP integrity, manifest version, both worker bundles and asset digests.

A live delegation with a real model was not exercised.

## Installed version requires a reload

Installing a VSIX does not activate it. A running editor keeps its current extension version until the extension host reloads.

## Storage and rollback warnings carried forward

Versions 4.2.48 and earlier cannot replay version-2 request snapshots. Builds before 4.2.62 show prune-only recovery rows as unknown messages. This release does not migrate or rewrite stored tasks, and no existing task data was read during the release operation.

## Installation

Verify the attached VSIX against its SHA-256 file. Install separately on each extension host. The companion ZIP is optional, unchanged since 4.2.51, and requires separate manual Chrome installation.
