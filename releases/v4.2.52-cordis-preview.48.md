# Roo Code 4.2.52 - Cordis preview 48

Extension version: **4.2.52**. Git tag: **v4.2.52-cordis-preview.48**. Experimental GitHub prerelease, not a stable or marketplace release.

## Codex strict tool schema fix

The 4.2.51 Codex provider (OpenAI Responses) rejected `browser_action` control commands before execution. Strict tool-schema validation failed at `/properties/command/anyOf/1` because `required` did not include the declared `timeoutMs` property.

The Codex request builder now rewrites every object schema level, including `anyOf`, `oneOf` and `allOf` branches, array `items`, and `$defs` entries. The outer `command` schema declares no `type`, so its union branches previously kept optional fields out of `required` while the outer `required` list stayed unchanged. Each branch is now internally consistent.

No browser command behavior, approval requirement or capability set changes. Live browser use and activation remain unverified.

## Features retained from 4.2.51

Browser controls, native PDF reading, and mode/model preservation are unchanged. See the [4.2.51 release notes](v4.2.51-cordis-preview.47.md).

## Validation and limits

Focused implementation evidence: seven schema tests and 62 existing Codex provider tests pass, and the backend TypeScript check passes in the implementation workspace. Release gates cover isolated lint, packaging, isolated backend TypeScript checking, ZIP CRC and manifest identity, both worker bundles, feature markers, excluded-provider markers, source-to-commit hashes, asset SHA-256, GitHub server digest and size, and installed-file byte identity. These gates are not a full test suite, and installation does not imply activation.

Live CDP, certificate sessions, Chrome companion attachment, macOS behavior and end-to-end user workflows remain unverified.

## Storage and rollback warnings carried forward

Versions 4.2.48 and earlier cannot replay version-2 request snapshots. Rolling back does not convert snapshots. This release does not inventory, read, migrate, rewrite, prune or delete existing task storage. Preserve task storage before downgrading, and disable automatic updates before a deliberate rollback.

Closing a task blocked by an interrupted edit marker can overwrite UI history with an empty snapshot. Preserve the task directory before recovery. Avoid navigation while saving history edits.

Unfinished provider-connection checks and unrelated local editor, UI, Tetris, archive and research changes are excluded.

## Installation

Verify the attached VSIX against its SHA-256 file. Install separately on each extension host. This release operation installs only on the current Linux code-server host, without reloading the editor or activating the new extension. It does not install on a Mac. The companion ZIP is optional, unchanged from 4.2.51, and requires separate manual Chrome installation.
