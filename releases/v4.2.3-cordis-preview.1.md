# Cordis runtime preview 1

Git tag: **v4.2.3-cordis-preview.1**. Extension version: **4.2.3**. This is a GitHub prerelease, not a stable or marketplace release.

## Enable or disable

Open Roo Code **Settings > Experimental > Cordis runtime preview**, set the checkbox, and **Save**. The setting is **off by default**, including upgrades without a saved value.

- **On:** new Anthropic tasks use the experimental request-admission path. Other providers use normal execution. Reopen or start a task to adopt the current setting.
- **Off:** normal chat and sequential delegation remain available. Disabling cancels active preview model requests, including condensation, and prevents further preview dispatch from those task instances. It cannot undo commands, writes, or other effects already performed.
- Re-enabling does not automatically resume stopped tasks. Reopen or start a task explicitly.

The switch does not remove the refactored code or bypass explicit capability restrictions. It controls use of the preview runtime. There is no graph scheduler or graph execution UI in this release, and admission does not enforce a financial spending cap.

## Included

- Existing checkpoint subtask/delegation policy and model-operation controls are retained. Normal root delegation remains available; exceptional deeper delegation requires its existing per-action approval.
- Shared invocation-policy and task-wide approval-veto interfaces with default compatibility behavior.
- Pinned Anthropic request configuration and inputs, physical-request admission identities, cancellation propagation, and explicit transport outcomes.
- Condensation admission failures propagate without fallback truncation or automatic retry. SDK retries and task-level automatic repair/retry are disabled on the mediated path.
- The preview switch and explanation are translated into all 18 supported languages.
- Local environment files are excluded from the package.

## Install and test

Download the attached **roo-cline-4.2.3.vsix**, install with the editor's **Install from VSIX** command, and run **Developer: Reload Window**. The extension ID is unchanged, so this replaces the existing Roo Code extension rather than installing a second copy.

First test with the switch off: normal chat, read/write approvals, command approval/rejection, cancellation, condensation, and sequential subtasks. Then enable it, save, and start a new Anthropic task. Test disabling during a model request or condensation; no further preview requests should be admitted from that stopped task. Normal existing tasks are not stopped by this toggle.

## Limitations and rollback

Graph execution, durable budgets, financial guarantees, worker isolation, other mediated providers, and independent auxiliary model calls are not implemented by this preview. Process-local controls are not a sandbox. Unsupported providers retain ordinary behavior when the UI preview setting is on.

To stop using the preview runtime, turn off the setting and save, then reopen or start a normal task. To roll back the extension itself, install the previous 4.2.2 package preserved at checkpoint **a9206b5fd** on the local **stable** branch, then reload. No task-history migration is introduced by this preview.
