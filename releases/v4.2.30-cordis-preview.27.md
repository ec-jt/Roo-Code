# Roo Code 4.2.30 - Cordis preview 27

Extension version: **4.2.30**. Git tag: **v4.2.30-cordis-preview.27**. Experimental GitHub prerelease, not a stable or marketplace release.

## In-app GitHub release updates

- Add **Check for updates** and **Update / install latest** in **Settings > About**. Check only this fork, **ec-jt/Roo-Code**, including stable releases and Cordis previews.
- Add **Automatically install GitHub release updates**, off by default and requiring native confirmation. Consent is local to the extension host, not enabled by importing Roo settings.
- Check at startup and every six hours when automatic updates are enabled. Skip automatic work while a Roo task is loaded. Recheck task state and consent before installation.
- Download to a private temporary directory, verify the SHA-256 sidecar and available GitHub asset digest, inspect archive safety and extension identity, then pass the verified VSIX URI to VS Code's installer. Reject failures without an unverified or shell-based fallback.
- Leave reloading manual. Do not uninstall Roo or remove its tasks/settings. Marketplace auto-update remains separately controlled by VS Code.

**This is the bootstrap release:** install 4.2.30 once through **Extensions: Install from VSIX**, then use About for subsequent newer releases. Remote SSH/local installations must be updated separately. Actual installation and remote targeting through the new updater have not been verified end to end. The updater uses direct HTTPS; mandatory proxy environments may require manual installation. See [release updates](../docs/release-updates.md).

## Compact reasoning tails

- Keep reasoning in its dedicated renderer after the preview limit instead of changing to a frozen plain-text prefix.
- Send the newest 4 KiB of reasoning to the chat, with Unicode-safe suffix boundaries. Preserve full stored history and model context.
- Collapse reasoning by default while honoring an explicit saved expanded preference.
- Show a **Reasoning…** activity indicator while the latest reasoning message is streaming, even when collapsed.
- Limit the expanded preview to a short scrollable block. Follow new text automatically, pause when the user scrolls up, and provide **Follow latest**.
- Provide **Open full reasoning** through the existing bounded native editor.

148 distinct focused tests passed: updater discovery, verification, lifecycle and UI (110), plus reasoning transport and UI (38). Backend and frontend type checks passed. Existing release archives were inspected read-only to check ZIP compatibility. No live GitHub updater download/install, Remote SSH updater integration, live-provider call, interactive VS Code rendering, or real-filesystem crash-injection test was performed.

Checksums detect corruption or mismatch, not compromise of the release publisher. Automatic installation requires trusting this repository. The updater's idle check is extension-host-local, not a machine-wide lock. Browser sandbox and SSH setup remain manual. Compaction requires input to fit the selected model, and recovery branches require exact pre-event snapshots.

## Known unresolved findings

- **Closing a task blocked by an interrupted assistant-edit marker can overwrite its UI history with an empty snapshot.** Preserve the task directory before attempting recovery.
- **Closing or switching during an assistant edit can leave the task stuck after a safe rollback.** Avoid navigation while an edit is saving.
- Checkpoint-based user edits can be dropped if replacement history loading exceeds the fixed continuation delay. This is separate from the checkpoint-menu restore operation.
- Approving an unrelated command can mark an older denied file edit as approved in the UI and file summary. This does not execute the denied write.
- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

Project memory remains opt-in. Cordis runtime preview remains off by default. New labels/help use English. The Mac grey-panel incident remains unverified.

## Install and rollback

Install **roo-cline-4.2.30.vsix**, verify its SHA-256 checksum, then run **Developer: Reload Window** when ready to interrupt the extension session. Install separately on each extension host.

The previous 4.2.29 prerelease remains available but lacks the updater and reasoning-tail fix. Disable automatic GitHub updates before a deliberate rollback. Versions below 4.2.29 do not honor the separate truncation-fallback preference. Do not open unfinished recovery branches in versions below 4.2.26. Resolve interrupted assistant edits before downgrading below 4.2.22. Rollback does not recover rewound messages, undo stored edits, restore files, erase memories, or stop detached processes.
