# Roo Code 4.2.76 - Cordis preview 72

Extension version: **4.2.76**. Git tag: **v4.2.76-cordis-preview.72**. Experimental GitHub prerelease, not a stable or marketplace release.

## Computer use in every mode

`computer_action` is now available in every mode: Code, Architect, Ask, Debug, Orchestrator, and custom modes without the `computer` group. Before this release, only Code mode and custom modes with the `computer` group could use it.

The tool is still opt-in. Roo offers it only when both of these are true:

- **Settings > Computer Use > Enable desktop control** is on.
- The selected model accepts images.

`disabledTools` still removes it. Approval, the app allowlist, background mode, and the stop command are unchanged.

> **Warning:** With desktop control on, read-only modes such as Ask and Architect can now click and type in other apps. To keep a mode away from the desktop, turn desktop control off or add `computer_action` to `disabledTools`.

## Changes

- `src/shared/tools.ts`: `computer_action` added to `ALWAYS_AVAILABLE_TOOLS`. The `computer` tool group is kept for compatibility.
- `src/core/prompts/tools/filter-tools-for-mode.ts`: the desktop-control check now runs inside the always-available branch of `isToolAllowedInMode`. Without this change, the early return for always-available tools would skip the check.
- `docs/computer-use.md`: the Code-mode requirement is replaced.
- `docs/architecture/evaluation-2026-11-18.md`: the protocol now tests 4.2.75 with macOS paths, and each worktree deletes its own copy of the protocol.

## Validation

- Focused tests pass (4 files, 45 tests): `filter-tools-computer-action.spec.ts` (new cases for architect, ask, debug, orchestrator, and a custom mode with and without the setting), `build-tools.computerAction.spec.ts`, `native-tools-filtering.spec.ts`, and `validateToolUse.spec.ts`.

Not yet verified: the tool offered in Architect mode in a live task.

## Installed version requires a reload

Installing a VSIX does not activate it. A running editor keeps its current extension version until the extension host reloads.

## Storage and rollback

No new settings and no stored-task changes. Earlier builds hide the tool outside Code mode again.
