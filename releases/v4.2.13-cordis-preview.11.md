# Roo Code 4.2.13 - Cordis preview 11

Extension version: **4.2.13**. Git tag: **v4.2.13-cordis-preview.11**. This is a GitHub prerelease, not a stable or marketplace release.

## Built-in filesystem and Markdownify recovery

- File-read, directory-listing, search, and Markdownify execution failures now return through the normal tool-error path instead of escaping without completing the tool turn.
- These operations have a 60-second execution deadline after approval. Time spent waiting for approval does not count toward the deadline.
- Task cancellation stops waiting for these operations. Late results and late failures are not published into a later turn.
- Markdownify URL conversion keeps browser setup, conversion, and cleanup in one serialized lifecycle operation. A late operation cannot close the browser underneath a subsequent conversion.
- Unsupported filesystem actions return an explicit error rather than completing without a result.

These changes apply to the built-in tools, not external MCP servers. They do not require enabling Cordis runtime preview, which remains off by default. Approval and access restrictions remain unchanged.

## Validation and limits

48 focused tests passed, including operation errors, deadlines, cancellation, late results, approval waits, browser cleanup, and message-loop continuation after file-read failures.

The exact reported live stall has not been reproduced. The deadline releases the task's wait; it does not forcibly interrupt every underlying file or browser operation, nor can it interrupt a parser that blocks the extension's event loop. Browser cleanup remains best effort, and a permanently stalled browser operation can block subsequent conversions on that task's browser service.

## Install and rollback

Install **roo-cline-4.2.13.vsix**, verify the accompanying SHA-256 checksum, and run **Developer: Reload Window**. The extension ID is unchanged.

The previous 4.2.12 prerelease remains available for rollback. Rollback removes these recovery changes and cannot undo completed task actions.
