# Roo Code 4.2.23 - Cordis preview 20

Extension version: **4.2.23**. Git tag: **v4.2.23-cordis-preview.20**. Experimental GitHub prerelease, not a stable or marketplace release.

## Compact only on explicit context overflow

- Send requests without proactive percentage- or reserved-token-based compaction or truncation.
- Default to one compaction attempt and one request retry only after an explicit provider input/context-limit rejection, before assistant content or tool calls are emitted.
- Preserve the newest user input and its tool-call/result exchange. If summarization or the retry fails, stop for manual intervention rather than silently truncating or looping.
- Keep manual compaction available. Turning off Compact on context overflow selects manual-only behavior; existing disabled settings remain respected.
- Show reported context usage against the full advertised window. The percentage is informational, not a trigger. Remove obsolete threshold sliders; retain old values only for settings compatibility.
- Preserve explicit overflow errors through mediated Anthropic admission and relevant OpenAI Native/Codex error paths. Summary and retry still require normal admission. Prepared replay branches remain immutable.

The unreleased size-aware 32K safety-margin proposal is superseded by this policy. See [context policy documentation](../docs/context-budget.md).

## History preview fixes

- Hide empty command-status placeholders instead of showing blank preview rows and full-message buttons.
- Label bounded tool previews with the tool name when available. Command-output previews remain collapsed until expanded.
- Attach exact row indices and per-row truncation flags to webview projections, avoiding ambiguous timestamp lookups and incorrect preview classification.
- Reject stale full-message requests and explain empty entries instead of opening blank documents.
- Use unique native preview document URLs across extension reloads to avoid cached-document reuse.

Authoritative task history is not deleted or migrated by these preview changes.

## Validation and limits

Focused recovery, error-classification, admission, adapter, history, and UI checks passed, including once-only recovery, cancellation, persistence failure, no replay after emitted output, timestamp collisions, and empty preview handling. Backend and webview type checks passed. No live-provider, full provider-matrix, interactive native-editor, or Mac memory-pressure test was performed.

Providers must expose a recognizable explicit context-limit rejection. Output limits still apply to API requests. A summary or a large preserved input can itself exceed provider limits; Roo then stops for manual intervention. Full backend history and whole-history snapshots still consume memory. The earlier Mac grey-panel incident remains unverified.

## Known unresolved preview findings

- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

Project memory remains opt-in. Cordis runtime preview remains off by default. Tool approval and storage settings are unchanged. New explanatory labels use English.

## Install and rollback

Install **roo-cline-4.2.23.vsix**, verify its SHA-256 checksum, then run **Developer: Reload Window** when ready to interrupt the extension session. Install separately on each extension host, including a separate Mac installation.

The previous 4.2.22 prerelease remains available for rollback and restores its proactive context policy. Resolve interrupted assistant edits before downgrading to versions older than 4.2.22. Rollback does not undo history edits or compaction, erase external memories, stop detached processes, or undo completed actions.
