# Roo Code 4.2.81 - Cordis preview 77

Extension version: **4.2.81**. Git tag: **v4.2.81-cordis-preview.77**. This is an experimental GitHub prerelease. It is not a stable release or a marketplace release.

## Changed: text-only replies retry once before the task pauses

With the Cordis runtime preview on, a model reply that had text and no tool call stopped the task at once and asked you to resume (`resume_task`). Normal Roo instead sends a reminder to use a tool and retries.

So an autonomous task stopped when the model wrote a summary and did not call `attempt_completion`. This happened in evaluation run S2-cordis-r2.

A new setting controls this behaviour. It is in Settings > Experimental, below "Cordis runtime preview":

- **When the model replies without a tool**
    - **Retry once, then pause** (default, `retryThenPause`): after the task has used a tool, the first text-only reply sends the standard reminder to use a tool or `attempt_completion`, and the task continues. If the next reply is also text only, the task pauses and asks you to resume, as before.
    - **Always pause** (`alwaysPause`): the earlier behaviour. Every text-only reply pauses the task.

With both values, a text-only reply before the task has used any tool still pauses at once. This keeps chat-style first turns interactive.

The Cordis retry does not add `MODEL_NO_TOOLS_USED` error rows and does not increase the mistake count. A tool call resets the count of text-only replies.

- `packages/types/src/global-settings.ts`: new global setting `cordisTextOnlyTurnPolicy` (`"retryThenPause"` | `"alwaysPause"`, default `"retryThenPause"`).

## Installed version requires a reload

Installing a VSIX does not activate it. A running editor keeps its current extension version until you reload the window.

## Storage and rollback

This release adds one optional global setting, `cordisTextOnlyTurnPolicy`. If it is missing, the default `retryThenPause` applies. Earlier builds ignore the setting. If you roll back, every text-only Cordis reply pauses the task again.
