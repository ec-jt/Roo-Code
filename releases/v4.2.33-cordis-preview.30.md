# Roo Code 4.2.33 - Cordis preview 30

Extension version: **4.2.33**. Git tag: **v4.2.33-cordis-preview.30**. Experimental GitHub prerelease, not a stable or marketplace release.

## Anthropic, OpenAI, and DeepSeek switching compatibility

- Fix request construction when switching an existing task between the direct Anthropic, OpenAI Native, and DeepSeek providers using **Use for next request**.
- Preserve conversation text and completed tool-call/result pairs. Keep the current response on its existing handler until the next request boundary. Do not replay tools or mutate saved history to perform a switch.
- Exclude standalone OpenAI Responses reasoning items from Anthropic and OpenAI Chat Completions messages instead of dereferencing their absent content or sending an incompatible item.
- Preserve native Claude thinking signatures. Keep adaptive Claude thinking enabled for imported history. For manual-thinking Claude, use a request-only non-thinking fallback when the final assistant turn lacks the required thinking block.
- For DeepSeek thinking requests with tool context, check every historical assistant turn for usable plaintext reasoning before merging messages. If required reasoning is missing, explicitly disable thinking for that request rather than fabricate reasoning or discard history.
- Preserve all plaintext reasoning blocks and reasoning from merged assistant messages, rather than keeping only the last block.

The DeepSeek fallback addresses the reported 400 missing-reasoning error after switching from GPT. GPT encrypted reasoning cannot be converted into DeepSeek reasoning. Compatibility mode may remain active while incompatible turns remain in effective history.

## Scope and validation

247 distinct focused tests passed, with one pre-existing skipped test. Coverage includes all six direct-provider switching directions, OpenAI Chat Completions and Codex formatting, native reasoning preservation, and deferred profile application. Extension type checking passed. Release lint, packaging, archive integrity, and checksum verification are required by the release procedure.

These checks validate locally constructed requests, not live API acceptance by every model or account. No private conversation was added to tests or uploaded as an issue. Credentials, model access, context capacity, and image/tool capabilities still apply. Pinned replay profiles and the experimental Anthropic-only mediated runtime retain their safety restrictions.

**LiteLLM limitation:** Shared conversion fixes also affect LiteLLM/OpenAI-compatible routes, but the direct Anthropic/DeepSeek thinking fallbacks do not automatically apply to proxy aliases. Switching Claude or DeepSeek thinking models through LiteLLM remains incomplete and unverified. No live proxy route was tested, including routes serving actual OpenAI models.

## Known unresolved findings

- Subtask links can select the wrong child after earlier delegation messages leave the bounded page, or when historical results use the latest completed-child ID.
- Long command-output previews can freeze on the beginning instead of following the tail.
- Image-only historical/preview messages can appear empty.
- Historical truncation events can hide structured count, reason, and token metrics.
- Same-millisecond timestamps can share expansion state or confuse timestamp-based lookups.
- **Closing a task blocked by an interrupted edit marker can overwrite UI history with an empty snapshot. Preserve the task directory before recovery.**
- **Closing or switching during a history edit can leave a task stuck after rollback. Avoid navigation while saving.**
- An unrelated approval can mark an older denied file edit as approved in the UI without executing that write.
- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

The pre-existing historical-action guard fixture failure remains outside this change. Project memory remains opt-in. Cordis runtime preview and automatic GitHub updates remain off by default. Browser security and SSH setup remain manual. The Mac grey-panel incident remains unverified.

## Install and rollback

From 4.2.30 or later, use **Settings > About > GitHub release updates** after closing the loaded task. Alternatively install the attached VSIX and verify its SHA-256 checksum. Run **Developer: Reload Window** when ready to activate it. Install separately on each extension host. End-to-end in-app Remote SSH installation remains unverified.

The previous 4.2.32 prerelease remains available. Disable automatic GitHub updates before a deliberate rollback. Versions below 4.2.29 do not honor the separate truncation-fallback preference. Do not open unfinished recovery branches in versions below 4.2.26. Resolve interrupted history edits before downgrading below 4.2.22. Rollback does not recover rewound messages, undo edits, restore files, erase memories, or stop detached processes.
