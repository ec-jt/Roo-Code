# Roo Code 4.2.14 - Cordis preview 12

Extension version: **4.2.14**. Git tag: **v4.2.14-cordis-preview.12**. This is a GitHub prerelease, not a stable or marketplace release.

## Research retrieval and local sources

- Shared tool-use guidance now directs the model to change retrieval methods after an execution error or timeout rather than repeatedly retrying the same failing tool.
- For sustained research, prefer reusable local copies of relevant public repositories or papers in the project's research location, or a task-specific folder under `research/` when none exists and writes are permitted.
- Prefer targeted file downloads for small lookups, shallow clones or pinned archives for multi-file investigations, and official HTML/text or locally extracted PDFs for papers.
- Record source URLs, retrieval dates, local paths, and repository revisions or paper versions. Search actual source material and cite relevant files, lines, pages, or sections.
- Downloads must be bounded and verified. Preserve approval and access restrictions, inspect archives before extraction, and do not execute downloaded code or automatically commit research artifacts.
- The Markdownify description now points to these fallback methods when conversion fails.

This is model guidance, not an automatic shell fallback or a guarantee of model compliance. It does not grant additional command or filesystem permissions. The 4.2.13 tool-error recovery, execution deadlines, and cancellation handling remain included. Cordis runtime preview remains off by default.

## Validation

All seven focused tool-use-guidance tests passed. No live research download workflow was exercised for this prompt-only change.

## Install and rollback

Install **roo-cline-4.2.14.vsix**, verify the accompanying SHA-256 checksum, and run **Developer: Reload Window**. The extension ID is unchanged.

The previous 4.2.13 prerelease remains available for rollback. Rollback removes this new research guidance and does not remove downloaded research artifacts or undo task actions.
