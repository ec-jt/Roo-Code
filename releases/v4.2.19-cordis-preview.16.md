# Roo Code 4.2.19 - Cordis preview 16

Extension version: **4.2.19**. Git tag: **v4.2.19-cordis-preview.16**. Experimental GitHub prerelease, not a stable or marketplace release.

## API cancellation listener cleanup

- Use a shared cancellable wait for the first and remaining provider chunks. Remove the temporary abort listener after success, rejection, synchronous iterator failure, or cancellation, even if the provider never settles afterward.
- Observe late provider rejections after cancellation without retaining the temporary listener.
- Remove the obsolete 100-listener warning override. Existing request-level cancellation, first-chunk retry handling, and task dispatch fences remain in place.

The outer per-chunk listener accumulation present in 4.2.14 was already fixed in 4.2.15. This release closes smaller remaining cleanup gaps; it does not establish the cause of any particular grey-panel incident.

## Validation

Seven focused cancellable-wait tests passed, including 251 consecutive fake iterator waits with bounded listener counts, synchronous/asynchronous failures, pre-cancellation, stalled cancellation, and late rejection. Four selected existing task-runtime tests passed; 53 unrelated cases in that file were not selected. No real-provider cancellation or Mac webview reproduction was performed.

## Large-history and existing limitations

This is **not a large-history rendering fix**. Full chat state transport, whole-history preprocessing, and snapshot persistence can still be expensive for long conversations. Preserve/export important history and use a concise handoff to a fresh task as an interim workaround. No task history is deleted or truncated by this update.

Stable and nightly use separate default storage. Matching custom-storage paths can cause overlap; two installed variants alone do not prove shared storage or explain lock failures. Installing this package on one extension host does not update a separate Mac installation.

The four preview 14 review findings remain unresolved:

- Global pip configuration can redirect managed-environment installation outside its approved destination. **Keep managed environments and their auto-approval disabled pending a fix.**
- Manual commands in Roo-owned terminals can be attributed to pending Roo commands. Avoid mixing manual work into these terminals when using Stop command.
- Named-pipe managed-environment manifests can block preparation or checkpoint compatibility inspection.
- Future interpreter paths supplied to pip can prevent recognition of compatible musllinux wheels.

Project memory remains opt-in. Cordis runtime preview remains off by default. Existing approval and storage settings are unchanged.

## Install and rollback

Install **roo-cline-4.2.19.vsix**, verify its SHA-256 checksum, then run **Developer: Reload Window** when ready to interrupt the extension session. Install separately on each extension host that needs the fix.

The previous 4.2.18 prerelease remains available for rollback. Rollback does not erase task history or external memories, stop detached processes, or undo completed actions.
