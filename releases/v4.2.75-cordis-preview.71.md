# Roo Code 4.2.75 - Cordis preview 71

Extension version: **4.2.75**. Git tag: **v4.2.75-cordis-preview.71**. Experimental GitHub prerelease, not a stable or marketplace release.

## Computer use: background mode (macOS)

New setting: **Settings > Computer Use > Background mode** (`computerUseBackgroundMode`, default off). It appears when desktop control is on.

With background mode on, Roo works without taking over the user's pointer, keyboard, or front window, so the user can keep using the computer at the same time. Only these actions run:

- `screenshot`, `list_windows`, `wait`
- `window_screenshot`: capture one window, even when covered
- `list_elements` and `click_element`: find and press buttons, menus, and fields by name through Accessibility
- `window_type`: insert text at a window's text cursor without bringing it to the front

Actions that use the shared pointer or keyboard (`click`, `double_click`, `right_click`, `move`, `drag`, `scroll`, `type`, `key`, `focus_window`) are refused before the approval prompt. The model gets an error that lists the allowed actions and tells it to ask the user to turn the mode off if the task cannot be done in the background. The tool description also explains the mode.

Outside macOS, background mode refuses every action, with a message that it is macOS-only.

Without background mode, behavior is unchanged: Roo takes turns with the user (4.2.73) and can use the background actions as a fallback.

## Validation

- Focused tests pass: the tool spec, including new background-mode tests (9 refused actions, 6 allowed actions, refusal outside macOS), and all desktop service specs (169 tests). The settings spec covers the new toggle (shown only when desktop control is on, value saved). TypeScript checks for types, extension and webview pass. Translations are complete for 17 locales.
- The background actions themselves were verified live on macOS in 4.2.73 and 4.2.74 (no pointer movement, front app unchanged).

Not yet verified: background mode end to end inside the editor with a live model.

## Installed version requires a reload

Installing a VSIX does not activate it. A running editor keeps its current extension version until the extension host reloads.

## Storage and rollback warnings carried forward

Earlier builds ignore the `computerUseBackgroundMode` setting. The warnings from 4.2.74 still apply. This release does not migrate or rewrite stored tasks.
